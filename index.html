FHEG Model Mathematical Proofs & Equations

สรุปสมการแกนกลางและการพิสูจน์คุณสมบัติทางคณิตศาสตร์ตาม Canonical Blueprint สำหรับอธิบายคณะกรรมการ

1. Road Slope ($s_e$)

$$s_e = \frac{z_j - z_i}{L_e}$$
คำนวณความชันจากระดับความสูงจริง ($z_i, z_j$) เหนือระดับน้ำทะเลปานกลาง และระยะทาง $L_e$

2. Flood Hazard Function ($H_e$) & Monotonicity

$$H_e = h_e(v_e + 0.5) + D_e$$
Proof of Monotonicity: $\frac{\partial H}{\partial h} = v + 0.5 > 0$ และ $\frac{\partial H}{\partial v} = h \ge 0$ รับประกันว่าความเสี่ยงจะไม่ลดลงเมื่อระดับน้ำหรือความเร็วการไหลเพิ่มขึ้น

3. Feasibility Constraint ($H_c = 1.25$)

$$e \in E_F \iff H_e < 1.25$$
ตัดช่วงถนนวิกฤต ($H_e \ge 1.25$) ออกจาก Feasible Subgraph $G_F$ ทันทีเพื่อความปลอดภัย

4. Hazard Attenuation Function ($\phi_p$)

$$\phi_p(H) = \left(\frac{H_c - H}{H_c - H_0}\right)^p,\quad H_0=0.25,\, H_c=1.25$$
ฟังก์ชันลดทอนความเร็วแบบต่อเนื่อง $\phi_p \in [0, 1]$ เชื่อมต่ออย่างราบรื่นที่ $H_0$ และ $H_c$

5. Movement Speed ($u_e$) & Tobler Function

$$u_e = V_T(s_e) \cdot \phi_p(H_e),\quad V_T(s_e) = 6 e^{-3.5|s_e + 0.05|}$$
ความเร็วเดินเท้าปรับตามความลาดชันของภูมิประเทศและระดับอันตรายจากน้ำท่วม

6. Risk-Equivalent & FHEG Edge Weight ($w_e$)

$$w_e(\lambda) = t_e + \lambda \cdot r_e,\quad \min W_\lambda(P) = T(P) + \lambda R(P)$$
Route Switching Threshold: $\lambda_{ij} = \frac{T_j - T_i}{R_i - R_j}$ สำหรับวิเคราะห์จุดเปลี่ยนผ่านเส้นทาง

7. A* Heuristic Admissibility & Consistency

$$h(n) = \frac{\text{dist}(n, \text{goal})}{u_{\max}} \le w^*(n, \text{goal})$$
Heuristic เป็น Lower Bound ที่แท้จริง รับประกันว่า A* จะค้นพบ Optimal Modeled Cost เสมอ

ที่มาของข้อมูลและบริการ Open APIs ทั้งหมดในระบบ

ระบบ Flood Safe Zone (FSZ) ใช้ข้อมูลภูมิสารสนเทศ อุทกวิทยา และระดับความสูงจริง 100% ฟรี ไม่ต้องผูกบัตรเครดิต และไม่มีค่าใช้จ่ายแอบแฝง:

1. โครงข่ายถนนจริง & จุดปลอดภัย (OpenStreetMap) Open Source

ดึงผ่าน Overpass API ในพิกัดเทศบาลเมืองแม่ฮ่องสอน (โรงเรียนห้องสอนศึกษา, ศาลากลางจังหวัด, วัดพระธาตุดอยกองมู, สนามกีฬากลาง)

2. ระดับความสูงภูมิประเทศจริง (Digital Elevation Model) Open Source

Copernicus 30m Global DEM & SRTM ผ่าน Open-Meteo Elevation API สำหรับคำนวณ Slope ($s_e$)

3. ข้อมูลอุทกวิทยาแม่น้ำปาย & ฝนสะสม (GloFAS & ECMWF) Open Source

Global Flood Awareness System (GloFAS) และ ECMWF Weather API สำหรับอัตราการไหล ($m^3/s$) และปริมาณฝน ($mm/h$)

4. ภาพถ่ายดาวเทียม & แผนที่ (Base Map Tiles) Free Tier

ESRI World Imagery Satellite, CartoDB Voyager & Dark Matter, OpenTopoMap (ไม่มีค่าใช้จ่าย)
